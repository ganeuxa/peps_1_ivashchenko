# Практическая работа №1. Основы работы с NI Multisim

Дисциплина «Программирование электронных приборов и систем», РТУ МИРЭА.
Выполнил Иващенко А.А., группа ЭФБО-07-24.

Устройство на МК семейства MCS-51 (8051): кнопка S1 на P1.0, светодиод LED1 на P1.3,
зуммер LS1 на P3.7 и семисегментный индикатор с дешифратором на P2.0–P2.3.
Каждое нажатие кнопки увеличивает счётчик 0–F на индикаторе и коротко включает зуммер.

## Содержимое

| Путь | Что это |
|---|---|
| `Схема Multisim/Lab1_MCU.ms14` | схема в NI Multisim 14.3 (МК DS80C320) |
| `Код/prog1.c` | программа на C для 8051 |
| `Proteus (проверка программы)/Lab1_8051.pdsprj` | та же схема в Proteus 8.17 на AT89C51 |
| `Proteus (проверка программы)/prog1.hex` | собранная прошивка |
| `Скрины/` | снимки экрана из отчёта |
| `Отчёт/Отчет_ПР1_Multisim.docx` | отчёт |

В Multisim 14.3 нет модуля MCU, поэтому программа проверялась в Proteus.

## Сборка прошивки

```
sdcc -mmcs51 prog1.c
packihx prog1.ihx > prog1.hex
```

Компилятор: SDCC 4.6.0. Готовый `prog1.hex` указывается в свойстве Program File у AT89C51,
частота 11,0592 МГц.
